# Батя в дискорде

Бот следит только за каналом `1283109126305611799` и отвечает случайной батиной фразой только когда пользователь `498130253038747648` пишет сообщение. Пользователь в фразах называется Нозар.

`BATYA_PHRASES` — список из 500 уникальных грубых фраз. Бот выбирает случайную строку через `random.choice(BATYA_PHRASES)`. В `phrases.py` стоят проверки на количество, уникальность и наличие мата в каждой фразе.

## Discord

1. Создайте приложение и бота в https://discord.com/developers/applications.
2. На странице Bot включите `Message Content Intent`.
3. Пригласите бота с правами `View Channel` и `Send Messages`.
4. Дайте доступ только к нужному каналу, если хотите жестко ограничить поведение.

## Переменные окружения

```text
DISCORD_TOKEN=токен_бота
TARGET_USER_ID=498130253038747648
TARGET_CHANNEL_ID=1283109126305611799
```

## Хостинг

Для Bothost используйте ветку `main` и включите собственный `Dockerfile`, если такая настройка есть.

```bash
python -m pip install -r requirements.txt
python -u bot.py
```
